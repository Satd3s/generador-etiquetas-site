# Rotuladora Web Pro

Generador e impresor universal de etiquetas de cinta para equipos, redes, servidores e inventario.

## Características
- Compatible con cintas de 6mm, 9mm, 12mm, 18mm, 24mm y 36mm.
- Modos: Cinta continua (hardware), Bandera para cables de red (doble vista), y Envoltura 360°.
- Listo para imprimir a escala real en hojas tamaño Carta / A4.
- 100% estático, sin dependencias externas.
